# 🧾 TAX System Integration

## 📋 المتطلبات والإعدادات لأي ربط جديد

لتهيئة النظام وربطه مع نظام الفوترة الضريبي الأردني، اتبع الخطوات التالية بدقة:

### ⚙️ 1. إعداد الاتصال بقاعدة البيانات

قم بتعديل بيانات الاتصال داخل الملف:

```
Tax/config/config.php
```

### 🔑 2. تعديل بيانات العميل (CLIENT_ID و SECRET_KEY)

قم بإضافة أو تحديث القيم التي حصلت عليها من موقع الضريبة في الملف التالي:

```
Tax/config/constants.php
```

### 🗂️ 3. تحديد مسار تخزين صور الـ QR

حدد المسار الذي سيتم فيه حفظ ملفات QR في نفس الملف:

```
Tax/config/constants.php
```

> ⚠️ مثال:
>
> ```php
> define('QR_DIR', '//192.168.0.7/Invoice/tax_Lusaka/');
> ```

### 🧾 4. تحديد رقم مصدر الدخل

قم بتعديل **السطر رقم 154** في الملف:

```
Tax/services/XmlService.php
```

واجعل قيمته رقم مصدر الدخل الخاص بالمكلف.

### 🚀 5. إصدار ملف الفاتورة (XML) وتشغيل الـ API

لتشغيل الخدمة وإنشاء ملف XML للفاتورة، استخدم الرابط التالي:

```
http://localhost/tax/Cash_sales?invoice=id
```

> استبدل `id` برقم الفاتورة المطلوب.

### 🧩 6. إنشاء وتخزين رمز QR للفاتورة

لتخزين صورة الـ QR الخاصة بالفاتورة، استخدم الرابط التالي:

```
http://localhost/tax/qr?invoice=id
```

> استبدل `id` برقم الفاتورة المطلوب.

---

### 💡 ملاحظات إضافية

* تأكد من أن صلاحيات المجلد المخصص للـ QR تسمح بالكتابة.
* يفضل استخدام **PHP 8.1+** لضمان التوافق.
* تأكد من أن **Oracle Client** مثبت ومهيأ بشكل صحيح للاتصال بقاعدة البيانات
